# 「初见雷达」— 底层需求分析 & 产品设计

> 分析时间：2026-11-01 | 版本 v0.1

---

## 一、底层需求分析

### 用户说的 vs 用户真的想要的

| 表面行为 | 底层心理需求 |
|---------|------------|
| 上传照片做颜值/印象测评 | **被看见、被理解** — "真实的我是怎样的？" |
| 看AI给出的评分和维度分析 | **权威背书** — "原来我是X型人/有X特质，有数据支撑" |
| 看到好评分享图后也想测 | **社交货币** — "我也要一张好看的结果图发朋友圈/小红书" |
| "被夸得很开心" | **情绪价值** — 日常被批评多，AI"客观"夸人更易接受 |
| 反复测、不同照片测 | **自我探索** — "不同角度/妆容的我，别人怎么看" |
| 测完想分享给朋友 | **关系货币** — "让朋友也来测，一起讨论" |

### 核心需求公式

```
情绪价值（被夸/被理解）
+ 社交货币（好看的结果图可分享）
+ 自我探索（了解自己在他人眼中的样子）
= 高传播意愿 + 高复访意愿
```

## 二、用户画像

### 主要用户群

#### 👩 第一主力：18-30岁女性（占70%+）
- **特征**：关注颜值、妆容、穿搭，活跃于小红书/抖音/朋友圈
- **动机**：想知道"我在异性/同性眼中是什么印象"、"适合什么风格"
- **传播**：天然愿意分享美照和测评结果
- **付费意愿**：高（为"变美"付费无压力）

#### 👨 第二主力：20-35岁男性（占20%）
- **特征**：好奇自己在女生/面试官/客户眼里的第一印象
- **动机**：改善社交形象、求职/社交场景准备
- **传播**：相对克制，但在男性圈子中话题性强
- **付费意愿**：中

#### 👧 第三群体：16-18岁高中生/大学生（占10%）
- **特征**：好奇、爱玩、喜欢新鲜事物
- **动机**：娱乐为主，顺便了解自己的风格
- **传播**：高频分享到班级群/朋友圈

### 用户旅程地图

```
听说/刷到（朋友分享/小红书笔记）
    ↓ 好奇：我也试试？
打开小程序/网站 → 3秒内看到上传入口
    ↓ 信任：这看起来靠谱/有趣
上传照片 → 看到AI分析动画（加载感）
    ↓ 期待：会给出什么结果？
查看结果 → "哇这描述太准了/太好笑了"
    ↓ 满足：情绪峰值
→ 想保存结果 → 分享到朋友圈/小红书/发给朋友
→ 想再测一张 → 回访
→ 朋友也来测 → 传播
```

## 三、同类产品分析 & 产品创意

### 颜值测评类产品设计模式

**成功的关键要素：**
1. **即时反馈** — 3秒内出结果，不让人等
2. **多维分析** — 不只是"颜值分"，而是"甜妹/御姐/少年感/氛围感"等有共鸣的维度
3. **好看的结果图** — 评分卡片设计精美，自带"发朋友圈"的欲望
4. **正向表达** — 哪怕是"分析缺点"也要包装成"提升建议"式的表达

### 🎯 产品创意池

#### 创意1：「初见雷达」（主体产品） ✅ 正在做
- **功能**：上传照片→AI从多维度分析他人对你的第一印象
- **维度**：颜值印象 / 风格气质 / 亲和力 / 记忆点 / 穿搭建议 / 妆容建议
- **特色**：结果用雷达图+文字描述+风格标签，一张图可分享
- **分享钩子**："我在『初见雷达』测了第一印象，你也来测测！"

#### 创意2：「社交人格扫描仪」
- **功能**：分析头像/照片→给出你在社交网络上的"人格标签"
- **维度**：头像吸引力 / 可信度 / 专业感 / 亲和力 / 辨识度 / 网感
- **特色**：结合小红书/朋友圈头像使用场景给出建议
- **分享钩子**：晒自己的"社交人格卡片"

#### 创意3：「约会印象预测器」
- **功能**：上传照片→AI模拟分析约会对象对你的印象
- **维度**：约会吸引力 / 约会可信度 / 约会氛围感 / 穿搭加分项
- **特色**：结果以"TA可能会这样看你"的叙事方式呈现
- **分享钩子**：闺蜜/兄弟间互测谁"约会印象分"更高

#### 创意4：「职场第一印象」
- **功能**：上传职场照/头像→AI给出求职/商务场景的第一印象分析
- **维度**：专业感 / 可信度 / 领导力潜质 / 亲和力 / 精致度
- **特色**：给具体的改进建议（领口颜色、眼神方向等）
- **分享钩子**：晒"职场印象雷达图"，匿名/不露脸

#### 创意5：「AI 灵魂关键词」
- **功能**：上传照片→AI从面部气质推断3-5个"灵魂关键词"
- **维度**：如"民国名伶感"、"日系氧气感"、"冷感学霸"等
- **特色**：关键词有故事感，引发"我是这种类型？"的讨论欲
- **分享钩子**：最纯粹的社交货币，直接晒关键词

## 四、分享驱动设计原则

### 为什么用户想分享？

1. **炫耀型** — 结果好看/描述正向，想晒
2. **寻求认同型** — "你们觉得准不准？"
3. **互动型** — "你也测一个，我们对比下"
4. **记录型** — 生成好看的卡片保存纪念

### 设计 Checklist

- [x] 结果页面设计精美（雷达图+评分+文字描述）
- [x] 一键生成分享卡片（自动生成精美海报图）
- [x] 分享文案预设（不同平台一键复制）
- [x] "再测一次"按钮（降低复测门槛）
- [x] 结果页底部有推荐钩子（测测你的XX风格）

## 五、技术方案

### AI模型：StepFun Step-1v-flash

**理由：**
- 中国大陆可访问，API稳定
- 支持多模态（图片+文字），视觉能力强
- Flash系列响应快，适合实时场景
- 价格合理（约 ¥0.01/张图）

### 技术栈

| 层级 | 技术 |
|-----|------|
| 前端 | Vite + React + Tailwind CSS |
| 后端 | Cloudflare Workers |
| AI | StepFun Step-1v-flash API |
| 图片生成 | StepFun 文生图 API（结果卡片） |
| 部署 | GitHub Pages + Cloudflare Workers |

### API Key 存放位置

```
.env                ← 前端本地开发用（不提交git）
wrangler.toml       ← Cloudflare Workers secrets
```
